Frequently Asked Questions

How do I undo the last commit without losing changes?

Run `git reset --soft HEAD~1`. Your changes will remain staged in the index.

How do I discard all local uncommitted changes?

Run `git restore .` and `git clean -fd` to remove untracked files.

Are these commands safe?

Each command in this cheatsheet is labeled with its safety level (Safe, Modifies, or Destructive).
