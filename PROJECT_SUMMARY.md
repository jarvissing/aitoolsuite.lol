## 3. How New Tools Are Added (The Autonomous Cloud Engine)

AI Tool Suite does not rely on manual coding for day-to-day expansion. It is powered by an **autonomous, self-optimizing CI/CD pipeline** running inside GitHub Actions.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    AUTONOMOUS CLOUD PUBLISHING PIPELINE                     │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
     ┌─────────────────────────────────┴─────────────────────────────────┐
     ▼                                                                   ▼
[ Step 1: Market Signal Scanner ]                   [ Step 2: Strict Safety Guardrails ]
• Analyzes GoatCounter traffic & Hacker News        • Rejects duplicate keywords
• Evaluates high-intent search queries              • Blocks off-topic / irrelevant tools
     │                                                                   │
     └─────────────────────────────────┬─────────────────────────────────┘
                                       ▼
                     [ Step 3: Template & Widget Engine ]
                     • Pairs tool keyword with dedicated interactive widget
                     • Injects FAQ Schema, WebApplication JSON-LD, OG tags
                     • Embeds Viral Share & Embed Toolbar
                                       │
                                       ▼
                     [ Step 4: 12-Point Automated QA Gatekeeper ]
                     • Validates meta tags, responsive viewport, H1 tags
                     • Tests working JS code (rejects empty placeholders)
                     • Enforces minimum 3 FAQ Q&A pairs & structured schema
                     • Aborts deployment instantly if ANY check fails
                                       │
                                       ▼
                     [ Step 5: Twice-Daily Autonomous Deployment ]
                     • GitHub Actions cron triggers: 09:00 UTC & 21:00 UTC
                     • Automatically regenerates index.html and sitemap.xml
                     • Commits & pushes to origin/main -> GitHub Pages Edge CDN
```

### Key Technical Guardrails:
- **Zero Duplication Guarantee:** Before any tool enters the pipeline, `market_analyzer.py` verifies that neither the keyword nor the URL slug exists on disk, preventing keyword cannibalization.
- **100% Client-Side Enforcement:** Every widget is built using vanilla JavaScript and standard Web APIs (Canvas, Crypto API, DOMParser, RegExp) so that zero backend server resources are required.
- **Automated QA Gatekeeper:** `qa_checker.py` runs a 12-point audit on every tool page before Git deployment. If a single page fails (e.g. missing FAQ or broken script), the push is immediately halted.
